# ASEAN Phonebook

## Project Description
The ASEAN Phonebook is a C# console application that stores, edits, 
and searches student contact information using ASEAN country codes.

This project demonstrates Object-Oriented Programming (OOP) and 
Git version control.

## Features
- Store student information
- Edit existing student entries using student number
- Search students by ASEAN country
- Search all countries
- Sort search results alphabetically by surname
- Validate country codes and gender inputs

## Supported Countries
- Malaysia - 60
- Indonesia - 62
- Philippines - 63
- Singapore - 65
- Thailand - 66

## Student Information
The program stores:
- Student Number
- Surname
- First Name
- Occupation
- Gender
- Country Code
- Area Code
- Phone Number

## Technologies Used
- C#
- .NET Console Application
- Git
- GitHub

## How to Run
1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Build the project using:

   dotnet build

5. Run the program using:

   dotnet run

## Data Storage
Student information is stored temporarily in memory.
The data is not saved permanently and will be lost 
when the program closes.

## Version Control
This project uses Git branches and commits to track 
the development of its features.
